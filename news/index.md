# Changelog

## paramix 0.0.2

CRAN release: 2025-06-10

- Extended documentation to clarify mathematical formulation of the
  mixing table.
- Added package hex logo in `man/figures/logo.png` and configured
  pkgdown favicons with light/dark theme support.
- Modernized CI pipelines migrated from `imuMAP`, including
  multi-platform R CMD check (Linux, macOS, Windows), automated linting
  with `air` and `lintr`, code coverage via Codecov, and automated
  pkgdown deployment.
- Standardized error and warning signaling using centralized templates
  in `R/messages.R` with dedicated unit tests.
- Integrated `roxyglobals` to automate global variable declarations in
  `R/globals.R`.
- Removed generated documentation (`man/*.Rd`) and intermediate vignette
  outputs from version control, managing them as transient build
  products generated by `just docs`.
- Added standard `justfile` developer workflows (`format`, `lint`,
  `docs`, `install`, `test`, `coverage`, `site`, `check`).
- Cleaned up and added linting validation for demonstration analysis
  workflows in `inst/analysis/`.
- Added dedicated vignette `reproducing-paper-analysis` documenting how
  to run the simulation study from Goodfellow et al. (2025)
  <doi:10.1371/journal.pcbi.1013420>, with citation metadata in
  `DESCRIPTION` and `inst/CITATION`.
- Added CI action and `just test-analysis` workflow to verify that the
  bundled analysis pipeline runs and reproduces all outputs from the
  installed package.
